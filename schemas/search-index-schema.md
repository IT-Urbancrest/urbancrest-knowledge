# Search Index Schema

`runtime/search-index.json` is generated by `scripts/build_search_index.py`.

## Top-level fields

- `schema_version`
- `repository`
- `repository_version`
- `generated_at`
- `timezone`
- `record_count`
- `config`
- `source_rules`
- `records`

## Record fields

Every record includes:

- `id`
- `record_type`
- `path`
- `title`
- `summary`
- `content`
- `priority`
- `category`
- `intents`
- `tags`
- `search_terms`
- `ministries`
- `audiences`
- `resources`

Specialized records may also include fields such as `staff_key`, `action_key`, `sort_start_utc`, `sort_end_utc`, `event_start`, `event_end`, `next_meeting`, `registration_url`, and `knowledge_file`.

The Base44 runtime should search this compiled file and send only the best matching records to the language model.
